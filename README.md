# ResearchDeck (リサーチデッキ)

楽天市場の商品ページから「実質仕入れ値」を自動計算し、Amazon SP-API（Amazon出品者用の外部データ連携システム）を経由して利益・出品可否・販売数を分析する個人リサーチ用Chrome拡張機能です。

## ⚡ 主な機能 (Features)

*   **実質仕入れ値 of 自動計算**: 楽天市場の商品ページ上で、獲得予定ポイントやクーポン割引を加味した実質仕入れ価格を自動的に算出します。
*   **Amazon SP-API リアルタイム連携**: AmazonのAPIと直接通信し、FBA（Amazonによる発送代行サービス）/ 自己発送それぞれの正確な手数料や利益率を算出します。
*   **出品可否の自動判定**: 該当商品のご自身のアカウントでの出品規制（ブランド規制や危険物指定など）の状態を検知し、出品できるかどうかを瞬時に判定します。
*   **セキュアなローカル管理**: 取得したAPI接続キー情報は、外部サーバーを介さずにお使いのブラウザ内（ローカルストレージ）のみに安全に保存されます。

## 🚀 導入手順 (Installation)

ツールをご自身のGoogle Chromeブラウザにインストールする手順です。

### 1. 拡張機能プログラムのダウンロード
1. こちらの直接リンク **[research-deck.zip をダウンロード](https://github.com/sugata38/research-deck/raw/main/research-deck.zip)** をクリックするか、本リポジトリの右側にある **「Releases（作成したプログラムの完成版を配布する場所）」** セクションから最新のファイルをダウンロードします。
2. ダウンロードしたZIPファイルをダブルクリックして解凍（展開）し、`research-deck` フォルダを取り出します。

### 2. Chromeへのインストール
1. Google Chromeブラウザを開き、アドレスバーに `chrome://extensions/` と入力してEnterキーを押します（拡張機能管理画面が開きます）。
2. 画面右上にある **「デベロッパー モード（開発中のプログラムをブラウザでテスト・使用するための特別な動作モード）」** のスイッチを **ON** にします。
3. 画面左上にある **「パッケージ化されていない拡張機能を読み込む」** ボタンをクリックします。
4. 先ほど解凍して取り出した `research-deck` フォルダを選択して読み込みます。
5. 拡張機能一覧に「ResearchDeck」が表示されればインストール完了です！

## ⚙️ 初期設定と接続キーの取得 (Setup)

本ツールを使用するには、ご自身のAmazonセラーアカウントから **4つの接続キー** を取得して設定する必要があります。

詳細な取得手順は、ステップ・バイ・ステップで確認できる以下のWeb版スライドマニュアルをご覧ください。

*   📖 **[Web版接続キー取得マニュアルを開く](https://sugata38.github.io/research-deck/docs/)**
    *(※GitHub Pagesによる公開設定完了後、上記のURLからアクセスできるようになります。)*

<details>

### 取得する4つの接続キー
1.  **出品者ID (Seller ID)**: アカウント固有の識別ID
2.  **LWA Client ID**: アプリケーションを識別するための専用ID
3.  **LWA Client Secret (クライアント機密情報)**: 認証に必要な暗号鍵
4.  **Refresh Token (リフレッシュトークン)**: 継続的な通信許可を得るための期限なしトークン

---

### ステップ別手順概要

1.  **出品者IDの取得**:
    セラーセントラル ➔ 右上の設定（歯車マーク） ➔ 「出品用アカウント情報」 ➔ 左側の「登録内容」の「出品者情報」 ➔ 「出品者トークン」をクリックして表示される英数字をコピーします。
2.  **アプリ開発画面を開く**:
    セラーセントラル左上メニュー ➔ 「アプリとサービス」 ➔ 「アプリの開発」をクリックします。
    *(※初回のみ、ソリューションプロバイダーポータルへの紐付け（オンボーディング）画面が表示されるので、画面の指示に従いメール認証等を完了させてください。)*
3.  **LWA情報の取得**:
    ソリューションプロバイダーポータルトップ画面 ➔ 登録されているアプリの「LWA認証情報」列にある「表示」リンクをクリックします。表示される「クライアントID」と、アコーディオンを展開して「クライアント機密情報（Client Secret）」をそれぞれコピーします。
4.  **リフレッシュトークンの取得**:
    ポータル画面でアプリの右端にある「アプリの編集」ボタンの右隣の「∨」矢印をクリック ➔ 「承認」を選択 ➔ マーケットプレイス「日本」の右側にある「アプリを承認」ボタンをクリック ➔ 発行された非常に長い「リフレッシュトークン」をコピーします。
5.  **ツールへの設定**:
    ResearchDeck of オプション画面（拡張機能のアイコン ➔ オプション）を開き、コピーした4つのキーを入力します。「接続テスト」をクリックして「接続成功」となることを確認し、「保存」を押して設定完了です。

## 💡 トラブルシューティング (Troubleshooting)

*   **接続テストが失敗する場合**:
    *   コピペした各キーの前後や途中に余分なスペース（空白文字）が入っていないか確認してください。
    *   特に「LWA Client Secret」や「Refresh Token」は非常に長い文字列のため、最初から最後まで漏れなくコピーできているか再確認してください。
    *   API権限の申請またはオンボーディング（利用登録プロセス）が完了しているか、セラーセントラル上でご確認ください。
